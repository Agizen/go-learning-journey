## 📖 About

This repository documents my progress learning **Go (Golang)** from scratch. Every project here was built step by step to practice core concepts before moving on to more advanced topics.

## 🧠 Concepts Covered So Far

- ✅ Program structure (`package`, `import`, `func main`)
- ✅ Variables (`var` and `:=`)
- ✅ Data types (`string`, `int`, `float64`)
- ✅ Output formatting (`Println`, `Printf`)
- ✅ User input (`Scanln`)
- ✅ Conditionals (`if` / `else`)
- ✅ The modulo operator (`%`)
- ✅ Loops (`for`, `continue`, `break`)
- ✅ Functions

## 📂 Projects

| # | Project | Description | Concepts Used |
|---|---------|-------------|----------------|
| 01 | [Personal ID Card](./01-personal-id-card) | Takes user input and prints a formatted personal info card | Variables, Input, if/else, Printf |
| 02 | [Sum of Numbers](./02-sum-of-numbers) | Calculates the sum of numbers from 1 to N | Loops, Accumulator pattern |
| 03 | [Biggest Number](./03-biggest-number) | Finds the largest of three user-provided numbers | Conditionals, Comparison logic |
| 04 | [Multiplication Table](./04-multiplication-table) | Prints the multiplication table for a given number | Loops, Formatted output |

> More projects are added as I progress through new topics 🌱

## 🛠️ How to Run

Each project is self-contained. To run any of them:

```bash
cd 01-personal-id-card
go run main.go
```
